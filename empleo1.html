Desarrollador Frontend

TekNova Medellín Híbrido Tiempo completo
Postularme Volver a empleos
Descripción del cargo

Buscamos un Desarrollador Frontend con pasión por crear interfaces modernas, funcionales y centradas en la experiencia del usuario. En este rol trabajarás en la construcción de productos digitales robustos, rápidos y visualmente atractivos.

Serás parte de un equipo multidisciplinario que valora la creatividad, la calidad del código y la mejora continua. La persona ideal combina buen criterio visual con pensamiento técnico, resolución de problemas y capacidad de entrega en entornos de trabajo ágil.

Responsabilidades
  • Desarrollar interfaces web responsivas con HTML, CSS y JavaScript moderno.
  • Trabajar con React para construir componentes reutilizables y de alto rendimiento.
  • Colaborar con diseño y producto para convertir prototipos en experiencias funcionales.
  • Optimizar tiempos de carga, accesibilidad y calidad visual de la plataforma.
  • Participar en revisiones de código, mejoras continuas y pruebas de usabilidad.
Requisitos
  • Experiencia mínima de 2 años en desarrollo frontend con React o tecnologías equivalentes.
  • Domino de HTML5, CSS3, JavaScript ES6+, componentes reutilizables y diseño responsive.
  • Conocimiento de Git, consumo de APIs y buenas prácticas de desarrollo web.
  • Capacidad para trabajar con metodologías ágiles y colaborar con otros equipos.
  • Interés por la experiencia de usuario, accesibilidad y diseño visual.
Qué ofrecemos
Salario $3.500.000 – $5.000.000
Horario Lunes a viernes
Prestaciones EPS, ARL, cesantías, auxilio de transporte
Desarrollo Capacitación y crecimiento profesional
